## Дипломный проект "Треккер задач"

---
### Описание:
Приложение "Треккер задач" для регистрации сотрудников в компании, создания задач, удобным и эффективным
распределением задач между сотрудниками. Создавать, изменять и удалять задачи может только управляющий.
При назначении задачи, сотрудникам приходит уведомление на почту. Статус задачи изменяется на "В работе".

Сотрудники могут пользоваться приложением только для просмотра своих задач, а так же отмечать,
когда задача выполнена. Задача переходит в статус "на проверке". Управляющий может отправить задачу на
доработку или завершить ее (для этого реализованы отдельные эндпоинты)
---
В проекте реализованы 2 приложения:
* `task_tracker`
    - Реализована модель Tusk.
    - Реализован сериализатор с необходимыми полями.
    - Реализована валидация входящих запросов.
    - Реализован CRUD а так же эндпоинты изменения статуса задач.
    - Реализована отправка сообщений по email для уведомлений сотрудников о назначенных им задач.
    - Реализован контроллер для отображения важных задач (задачи, не взятые в работу, у которых родительская задача в работе
    - Реализована пагинация для отображения списка задач.
    - CRUD поктыт тестами более чем на 75%

* `users`<br /> 
  - Реализована модель User.
  - Реализован сериализатор с необходимыми полями.
  - Реализованы права доступа. Сотрудник(IsExecutor) может просматривать только список задач, назначенный ему.
Управляющий(IsAdmin) может делать всё.
  - Реализован CRUD а так же эндпоинты регистрации и авторизации пользователей.
  - Реализован эндпоинт для отображения списка сотрудников с их задачами, отсортированный по количеству задач.
  - Реализована кастомная команда создания суперпользователя `python manage.py csu`.
  - CRUD поктыт тестами более чем на 75%
---
- Необходимые данные для работы приложения спрятаны в переменные окружения `.env` файл.
- Реализована авто-генерируемая документация API.
- Реализован CORS.
- Реализовано логирование для сохранения логов в отдельном файле.

### Запуск проекта с использованием контейнеризации:

1. Запустить Docker на вашем компьютере. Если его нет, установить можно по ссылке: [Docker](https://www.docker.com/)
 
2. Клонировать репозиторий: [task_tracker](https://github.com/Ascon29/task_tracker_diplom/)
 
3. Собрать и запустить контейнеры:
```bash
docker-compose up -d --build
```
При успешном запуске приложения в консоль будет выведено сообщение:<br />
```
    ✔ Service web                          Built
    ✔ Network task_tracker_diplom_default  Created
    ✔ Container task_tracker_diplom-db-1   Started
    ✔ Container task_tracker_diplom-web-1  Started
``` 
4. Создать суперпользователя:
```bash
docker-compose exec web python manage.py csu
```
- логин: admin@example.com
- пароль: 123

5. Сервер доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
6. API документация доступна по ссылкам [swagger](http://127.0.0.1:8000/swagger/), [redoc](http://127.0.0.1:8000/redoc/)
