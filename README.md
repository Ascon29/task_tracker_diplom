Приложение "треккер задач". Создавать, изменять и удалять задачи может только начальник.
Сотрудники могут пользоваться приложением только для просмотра своих задач, а так же отмечать,
когда задача выполнена. Задача переходит в статус "на проверке", начальнику приходит уведомление
об этом.

- реализованы модели задач и пользователей.
- реализован круд


в settings поменять
- DEFAULT_PERMISSION_CLASSES поменять AllowAny на IsAuthenticated
- ACCESS_TOKEN_LIFETIME на 10 минут
